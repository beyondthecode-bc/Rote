**Hardening release.** Rote now survives a tampered or corrupted state file (counters and lists are clamped on load instead of crashing), caps how deep and how far it walks an app's menus, resolves menu selections off the main thread so a misbehaving app cannot freeze it, limits menu titles to 256 characters and strips control characters, and logs nudged menu titles privately. The project also gained a SECURITY.md with private vulnerability reporting, pinned CI actions and Dependabot, and a release script that drafts, verifies and only then publishes each release.
