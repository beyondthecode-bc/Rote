**Security update, recommended for everyone.** The in-app updater now verifies every update before installing it: the download must match the SHA-256 published with the release, the archive must contain exactly `Rote.app`, and that app must carry BeyondTheCode's Developer ID signature and a newer version. The updater no longer removes the quarantine attribute and no longer runs a privileged shell command built from file names. An app that belongs to your user is replaced by a rename with no password, and the previous version is kept until the new one is verified in place. Updating from 1.0.1 still uses the old installer one last time, so it asks for an administrator password once.
